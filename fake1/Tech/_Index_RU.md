TECH INDEX — CLOUD NATIVE ENCODING PLATFORM

SCOPE

Этот Tech-пакет охватывает только самый актуальный проект Cloud Native Encoding Platform (апрель 2025 – настоящее время): технологии из его description, responsibilities и Environment. Технологии, встречающиеся только в проектах 2–8, исключены. Request для fake1 не предоставлялся.

Нормализация: Spring включает Spring Boot; FFmpeg включает libav, libavfilter и libavformat; Tree-sitter включает go-tree-sitter; HLS включает LL-HLS; MPEG-DASH включает LL-DASH; CEA-608/708 объединены; TTML включает IMSC; Akamai включает MSL4/MSL5; сервисы AWS, Azure и Google Cloud сгруппированы по провайдеру.
