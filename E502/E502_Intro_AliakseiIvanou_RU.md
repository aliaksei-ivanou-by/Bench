3. ТЕКСТ ДЛЯ ИНТЕРВЬЮ

Здравствуйте, меня зовут Aliaksei Ivanou. Я Software Engineer с более чем четырнадцатилетним коммерческим опытом. Мой основной фокус — C и C++ под Linux, включая разработку бэкенда, распределённые сервисы и интеграцию с объектными хранилищами. У меня также большой опыт разработки алгоритмов анализа изображений в MATLAB.

Удобнее всего описать мой опыт через домены, в которых я работал.

Первый домен — телекоммуникации и embedded Linux. С мая 2024 года я работаю в роли Software Engineer на SIP Desk Phone Platform for Audio and Video Communication. Платформа объединяет приложение на C++17 и Qt, кастомизированный Linphone SDK, WebRTC, Windows-инструмент провижининга и систему Linux на базе Yocto для оборудования NXP i.MX. Я занимаюсь обработкой звонков, интеграцией SDK, видеоконференциями, провижинингом и конфигурацией устройств. После обзора доменов вернусь к этому проекту подробнее.

Второй домен — спутниковые данные и облачные хранилища. С апреля 2022 по апрель 2024 года я работал в роли Software Engineer на Remote Sensing Satellites Database. Ruby on Rails обеспечивал работу с каталогами, поиском и метаданными, а PostgreSQL хранил структурированные записи. Я также разрабатывал на C++ компоненты загрузки больших архивов изображений и телеметрии с потоковым вводом-выводом POSIX, буферами памяти и многопоточной валидацией.

Для хранения я интегрировал Ceph RGW через S3 API, включая pre-signed URLs, и работал с сервисами Ceph в Kubernetes, используя Rook Operator и Ceph CSI для RBD. Ceph выбрали, чтобы на одной платформе получить S3-совместимый доступ к архивам и блочные тома для Kubernetes, сохранив структурированные данные каталога в PostgreSQL. Я исследовал производительность хранилища по задержкам ввода-вывода, пропускной способности, поведению OSD и использованию BlueStore. Скрипты на Python помогали проверять развёртывание и состояние системы, а Prometheus и Grafana использовались для мониторинга. Этот проект особенно релевантен роли, которая объединяет C++, хранилища и инфраструктуру.

Третий домен — обработка изображений для БПЛА и спутников. С марта 2020 по март 2022 года я работал в роли Software Engineer на Software Modules for UAV. Я сочетал разработку алгоритмов в MATLAB с компонентами обработки на C++ для дебайеризации, преобразования форматов, стабилизации и слияния изображений. Также я работал с эффективной обработкой буферов кадров и проверял результаты на представительных данных датчиков.

С января 2018 по февраль 2020 года я работал в роли Software Engineer на Software for Processing and Analysis of Satellite Earth Observation Images. Я занимался нормализацией яркости, анализом разрешения изображений, прогнозированием диапазона квантования, обработкой кадров и алгоритмом сжатия на базе ADPCM с несколькими квантователями.

Четвёртый домен — библиотечные системы. С января 2015 по декабрь 2017 года я работал в роли Software Engineer на Library System. Я разрабатывал бэкенд-модули на C, коммуникацию через сокеты и API endpoints на Scala, работал с Java, MySQL и PostgreSQL. Я интегрировал хранилище AWS S3 для цифровых коллекций и реализовал потоковую загрузку и скачивание диапазонов байтов для больших объектов. Также я занимался доступом к базам данных, совместимостью с существующими компонентами, подготовкой релизов и code review.

Пятый домен — нефтегазовая отрасль. С августа 2012 по декабрь 2014 года я работал в роли Software Engineer на Corporate System for the Oil and Gas Industry. Я разрабатывал и поддерживал бэкенд-компоненты на C++11 и интегрировал LevelDB для телеметрии и событий наряду с реляционным хранилищем. LevelDB выбрали для локального постоянного доступа сервиса к данным по ключу без отдельного сервера БД, тогда как реляционные базы использовались для корпоративных записей и запросов. Я работал над доступом к базам данных, настройкой кэша и compaction в LevelDB, интеграцией с веб-интерфейсом на JavaScript и jQuery и поддержкой унаследованного кода.

Теперь подробнее расскажу о последнем проекте SIP-телефона.

Продукт поддерживает аудиотелефоны и устройства с камерой. Он включает нативное приложение, веб-интерфейс управления, инструменты провижининга и настройку embedded-системы. Основные сценарии — SIP-регистрация, входящие и исходящие звонки, видео, удержание, перевод, конференции, телефонная книга и удалённая конфигурация.

Значительную часть моей работы составлял рефакторинг обработки звонков в Qt Widgets в направлении более чётких границ MVC и MVVM. Я отделял отображение интерфейса от состояния звонка, действий пользователя, согласования медиа и интеграции с Linphone SDK, сохраняя существующее поведение интерфейса и совместимость сигналов QObject. Я также улучшал обработку видео и конференций в случаях удержания, второго звонка, удалённого завершения, устаревших оверлеев и переключения активного видеопотока.

На уровне SDK я расширял кастомизированную бэкенд-логику liblinphone для переключения SIP и подключения к резервному серверу. Также я разрабатывал интерфейс и сигнализацию WebRTC-конференций: создание и присоединение к конференции, списки участников, диалоги приглашений, раскладку видео и управление аудио- и видеоустройствами.

Ещё одна область — Windows-инструмент провижининга. Я мигрировал конфигурационную утилиту WinForms с .NET Framework 4.8 на .NET 8, унифицировал форматы файлов проектов в экосистеме устройств и реализовывал сценарии провижининга с SNMP, DHCP, TFTP и SQLite.

На стороне устройства я участвовал в настройке Yocto и BitBake, интеграции NXP i.MX embedded Linux и конфигурации сервисов. В рабочее окружение входили systemd, CMake, gdb, Valgrind и Qt Test. Во всех этих доменах мой фокус — реализация и интеграция компонентов на C и C++, отслеживание данных между частями системы и поддержка существующих продуктов. Такое сочетание связывает мою работу с embedded и приложениями с опытом хранилищ и Kubernetes, полезным для этой роли.
