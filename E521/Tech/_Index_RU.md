УКАЗАТЕЛЬ TECH

Команды и примеры исходников/конфигурации оформлены блоками кода с указанием языка. Команды build-host, диагностика target и фрагменты рецептов разделены.

Раздел использования Yocto Project содержит flow интеграции Linphone SDK из двенадцати шагов: от выбора исходников и рецептов до зависимостей приложения, состава образа и проверки на устройстве.

Подборка содержит 136 вопросов с ответами и устойчивыми идентификаторами: по 24 для YCT, BB, EL и BSP и по 20 для SYS и IMX. Метки разделов и вопросов — обычный текст без зависимости от автоматической нумерации списков.

Объём: только Yocto Project, BitBake, Embedded Linux, systemd, NXP i.MX и BSP по прямому запросу. Остальные технологии CV и вакансии в эту подборку не входят.

МАРШРУТ ПО ЧЕКЛИСТУ

- Yocto Project: Poky/configuration, кеши и четыре упражнения: QEMU, CMake-приложение, изменения ядра и overlay платы.
- BitBake: build classes, разбиение пакетов, overrides, devtool, метаданные исходников/лицензий и QA.
- BSP: patches/fragments ядра, внешние модули, сборка device tree и overlays.
- Embedded Linux: boot/cmdline, SDK, target tools, интерфейсы оборудования и OTA/security.
- systemd: упаковка unit и включение через Yocto.
