УКАЗАТЕЛЬ TECH

Каждый ответ дополнен примером и проверками. Сначала даётся основная мысль, затем — что делать на практике и по каким признакам оценивать результат.

Объяснения и ответы написаны короткими фразами. Термины поясняются обычными словами; имена API, переменных и команды сохранены.

Команды и примеры исходников/конфигурации оформлены блоками кода с указанием языка. Команды сборочного компьютера, проверки телефона и фрагменты рецептов разделены.

Раздел использования Yocto Project содержит процесс интеграции Linphone SDK из двенадцати шагов: от выбора исходников и рецептов до зависимостей приложения, состава образа и проверки на устройстве.

Подборка содержит 150 вопросов с ответами и устойчивыми идентификаторами: по 26 для YCT и BB, по 27 для EL и BSP и по 22 для SYS и IMX. Метки разделов и вопросов — обычный текст без зависимости от автоматической нумерации списков.

Объём: только Yocto Project, BitBake, Embedded Linux, systemd, NXP i.MX и BSP по прямому запросу. Остальные технологии CV и вакансии в эту подборку не входят.
