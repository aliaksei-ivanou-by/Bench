04. ЧТО НУЖНО ФОРМУЛИРОВАТЬ ТОЧНО

Обоснованное описание фактической платформы телефона — NXP i.MX ARM64. Выбранное CV не называет точный SoC и MACHINE. Флаги кодеков i.MX и ссылка совместимости Qt в рецепте не определяют однозначно чип или плату. Аналогично совместимость Kirkstone в layer.conf не задаёт точную версию BSP, commit ядра или загрузчика.

Имя предоставленного рецепта и PV — latest. Строка версии CMake не закрепляет исходники. Точный commit установленного SDK берётся из записи соответствующей сборки или выпуска; чтение снимка не восстанавливает его автоматически. Версия GPIO API также не следует из слов libgpiod C++ API. Можно объяснить владение, блокирующее ожидание и освобождение, не придумывая последовательность вызовов 1.x/2.x и конкретное историческое место утечки.

Команда добавила Linphone SDK, WebRTC и mediasoup в начальную основу Yocto. Собственная работа над watchdog и переключением в SDK отличается от владения всем BSP, веб-интерфейсом и поздней переработкой сервера конференций. Большой рефакторинг Qt был внутренней архитектурной работой. Поддержка HA1 реализовывалась, но выбор этого режима был отключён в поздних выпусках. Поддерживаемый формат проекта JSON отличается от несовместимого прежнего зашифрованного BinaryFormatter.

В CV и фактическом профиле английский B2; C1 — требование запроса. Зафиксированный формальный грейд — middle, а Senior — целевая роль. Intro/Legend сохраняют хронологию выбранного CV; из устного Intro даты убраны по запросу. В Responsibilities отдельно записан фактический календарь. При ответе о датах нельзя смешивать эти две хронологии.

05. КАК ПОЛУЧИТЬ КОНКРЕТНЫЕ СВЕДЕНИЯ О СБОРКЕ И УСТРОЙСТВЕ

Эти команды предназначены для доступного окружения продукта; их вывод не наблюдался при данной проверке. Метаданные сборки и наблюдения на телефоне отвечают на разные вопросы. Сохраняются идентификатор образа и записи выпуска; один uname не устанавливает commit SDK.

КОМПЬЮТЕР СБОРКИ

```bash
bitbake-layers show-layers
bitbake-layers show-recipes linphone-sdk
bitbake-layers show-appends
bitbake -e linphone-sdk | \
    grep -E '^(MACHINE|DISTRO|PV|PR|PKGV|SRCREV|PACKAGECONFIG|S|B|RECIPE_SYSROOT)='
```

ТЕЛЕФОН, ЕСЛИ УКАЗАННЫЕ ИНТЕРФЕЙСЫ ДОСТУПНЫ

```bash
uname -a
cat /etc/os-release
cat /proc/cmdline
if [ -r /proc/device-tree/model ]; then
    tr '\000' '\n' < /proc/device-tree/model
fi
if command -v systemctl >/dev/null 2>&1; then
    systemctl --version
fi
```

Для версий SDK и libgpiod используются manifest выпуска, метаданные пакетов и записи реальной сборки библиотек. В разработческом образе могут быть утилиты вывода версии, но их отсутствие не доказывает отсутствие библиотеки. Аппаратное ускорение нельзя выводить из одного флага сборки: проверяется выбранный путь и соответствующая нагрузка.
