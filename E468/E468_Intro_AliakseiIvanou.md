Self Intro

Hello, my name is Aliaksei Ivanou. I am a Senior Software Engineer with more than fourteen years of commercial experience in software development.
I have a degree in Computer Science and Software Engineering. My main specialization is C and C++ development, but throughout my career I have also worked with Java, Scala, MATLAB, C#, JavaScript, and Ruby. My experience covers several technical areas, including embedded systems, telecommunications, multimedia, backend development, desktop applications, image processing, and integration between software and hardware.
I started my professional career in 2012 in the aerospace and Earth-observation domain. My first major project was software for processing and analyzing satellite images. I used C++ and MATLAB to develop algorithms for brightness normalization, optical-defect correction, image-sharpness analysis, and linear-resolution measurement.
I also worked on predicting quantization ranges for satellite images based on Earth-observation data and albedo values. Another important task was developing an image-compression algorithm based on adaptive differential pulse-code modulation, or ADPCM. This part of my career gave me a strong background in algorithms, mathematical analysis, image processing, and working with large amounts of technical data.
Later, I participated in a project for processing images received from UAV optical sensors. I developed several MATLAB modules, including a debayer algorithm for converting raw sensor data into full-color images, image-format conversion tools, an image-stabilization algorithm, and an image-fusion algorithm for combining information from multiple sensors.
I also worked on a database of Earth-observation satellites. That project was different from my main algorithmic work because it was a web application based on Ruby on Rails and PostgreSQL. I developed parts of the web interface, worked with the database structure and queries, and supported the migration of legacy data from Microsoft Access.
After that, I moved toward more general C++ development. I worked on 3D reconstruction software that generated 3D models from data received from multiple 2D laser sensors. We used the Point Cloud Library for point-cloud processing and Open3D for visualization and analysis.
I also developed a desktop application for personal financial accounting. It was written in C++ and used FLTK for the graphical interface and SQLite for local data storage. I used CMake for the build system, Google Test for automated testing, and plog for logging and diagnostics. This project gave me experience with the complete lifecycle of a standalone desktop application, including UI development, business logic, database integration, testing, and debugging.
From March 2022 until April 2025, I worked as a Senior Software Engineer on a large library management system. The product had more than forty years of development history and was used by clients in different countries.
It was a complex legacy system that combined C, Java 11, Scala, MySQL, and PostgreSQL. I was one of the main contributors working with the C codebase. My responsibilities included investigating and fixing complex defects, implementing new functionality, improving performance, and developing features related to socket-based communication.
I also refactored parts of the Scala API, modified database tables to support new workflows, and worked with existing AWS CI/CD pipelines. In addition to development, I estimated tasks and conducted code reviews for both my immediate team and the client’s team.
The main challenge on that project was making changes safely. Because the system was mature and had many dependencies, even a small modification could affect existing functionality. Before changing the code, I usually had to investigate the complete execution flow, understand the related database operations and communication logic, and evaluate possible side effects. This experience taught me how to work effectively with large legacy systems while preserving backward compatibility.
Currently, I am working on an embedded platform for SIP desk phones. The product includes models with and without cameras and supports audio calls, video calls, call hold and transfer, conferences, phonebook access, direct IP dialing, remote configuration, and automatic provisioning.
The main technology stack includes C++17, Qt 5, Qt Widgets, Embedded Linux, Yocto, Linphone SDK, SIP, SDP, RTP, GStreamer, V4L2, WebRTC, mediasoup, and libmediasoupclient. The target hardware is based on the NXP i.MX platform.
My main responsibility is the call-handling logic of the native application. One of my major tasks has been refactoring the existing call flow toward a cleaner MVC- or MVVM-style architecture.
Originally, UI rendering, call state, user actions, media negotiation, and direct interaction with Linphone SDK were tightly coupled. This made the code difficult to understand and made changes risky. I have been gradually separating these responsibilities into clearer domain, presentation, and SDK-integration layers.
Because this is an existing product, we cannot simply rewrite the entire application. The refactoring must be incremental and must preserve the existing UI behavior and compatibility with Qt signals and slots.
I also work on complex video-call scenarios. These include held calls, second-line calls, remote hangups, switching the active video stream, updating conference layouts, and removing outdated UI elements after the call state changes. The main challenge is keeping the application state, Linphone SDK state, UI state, and actual media state synchronized.
Another part of my responsibility is WebRTC conferencing. I have worked on conference creation and joining, incoming invitations, participant lists, conference controls, video-tile layouts, and audio and video device management.
I have also customized the Linphone SDK integration to support SIP failover and backup-server connectivity. The purpose of this functionality is to improve device reliability when the primary SIP server is unavailable.
In addition to the C++ application, I participated in migrating a WinForms provisioning utility from .NET Framework 4.8 to .NET 8. The provisioning functionality uses technologies such as SNMP, DHCP, TFTP, and SQLite. I also collaborate on Yocto and BitBake integration, systemd service configuration, and application deployment to the embedded NXP i.MX target.
Overall, I would describe myself as an engineer who is comfortable working with complex existing systems. I enjoy investigating difficult problems, understanding how different components interact, and improving the architecture without breaking existing behavior.
My strongest areas are C and C++, debugging, legacy-code modernization, multimedia and networking integration, and communication between software and hardware. I am especially interested in projects where performance, reliability, and maintainability are important.
At this stage of my career, I am looking for technically challenging work where I can use my C++ and system-development experience, contribute to architectural decisions, and continue working with complex products and modern technologies.
