ROLE SUMMARY

The project is seeking four to six Senior C++ Engineers, ideally including a hands-on Technical Lead, to support verification and validation of safety-critical software for an autonomous-driving solution. The engineers will work inside the client’s established development processes and toolchain and collaborate closely with its engineering team.

The work combines analysis and correction of existing modern C++ code, requirements-based unit and integration testing, coverage improvement, requirements traceability, technical documentation and formal code review. Particular attention is expected around memory allocation, compiler warnings, error handling and compliance with functional and technical safety requirements.

The Technical Lead must remain actively involved in C++ development and testing while guiding technical implementation across the team. All candidates are expected to work independently, communicate clearly in English and demonstrate practical C++ and testing skills during a live coding interview.
